Versión 4: sistema solar único. Los planetas intentan ser más reconocibles visualmente y puedes tocarlos para leer 3 datos importantes. Publica este archivo como index.html en GitHub Pages para usarlo por HTTPS.

Contenido: Sol y 8 planetas.
Interacción: toca un planeta para ver su ficha.
Uso recomendado: cubo oscuro sobre fondo claro y buena luz.

Para el aula: comparte el mismo enlace o QR con toda la clase. Los móviles personales no necesitan instalar nada, pero sí conceder permiso de cámara cuando Chrome lo solicite.

Notas importantes sobre esta versión

Este visor intenta detectar la silueta oscura del cubo sobre un fondo claro y superponer el sistema solar. El seguimiento es aproximado y no reconoce los seis patrones oficiales del MERGE Cube, por lo que puede perder la posición en algunos giros. Aun así, sirve como demostración didáctica y actividad de aula.

Funciona en el dispositivo: no envía imágenes a servidores. El motor de dibujo 3D se carga por Internet. No afiliado a MERGE.
